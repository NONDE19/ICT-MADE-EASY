# ICT Made Easy User Guide

## 1. Administrator Workflow

1. Sign in with an Administrator account (`admin@virtuolab.edu.zm` in dev mode).
2. **Schools:** Register schools with unique school codes, districts, and provinces, or deactivate schools when needed.
3. **Teachers & Pupils:** Create accounts assigned to specific schools and classes, or suspend/restore access.
4. **Classes:** Create grade-level classes and assign teachers.
5. **Modules & Settings:** Toggle module visibility, configure passing scores, and inspect security audit logs.

## 2. Teacher Workflow

1. Sign in with a Teacher account (`teacher@virtuolab.edu.zm` in dev mode).
2. Review class KPIs: assigned classes, registered pupils, average scores, and pupils needing support.
3. Click **Inspect** on any pupil row to review individual lesson completions and assessment results.
4. Click **Assign Practical Exercise** to create a Level 1, Level 2, or Level 3 task with automated grading criteria and a due date.

## 3. Pupil Workflow

1. Sign in with a Pupil account (`pupil@virtuolab.edu.zm` in dev mode).
2. **Dashboard:** View overall completion, recommended next lessons, assigned exercises, and achievements.
3. **Learning Modules:** Read structured lessons, interact with simulations (Abacus, Babbage Engine, 5 Generations, OS Scheduler), and complete end-of-topic quizzes.
4. **Hardware Lab:** Click components on the interactive system schematic, assemble a virtual PC, match components, and diagnose faults.
5. **Virtual Desktop:** Open File Manager, Word Writer, CalcSheet, SlideDeck, EduBrowser, Recycle Bin, and System Settings. Changes save automatically to your school database.
6. **Practical Assessment Centre:** Select Level 1 (Guided), Level 2 (Independent), or Level 3 (Assessment), complete the task on the embedded Virtual Desktop, and click **Submit Practical Attempt** for instant grading and feedback.
